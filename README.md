## Local Development

Clone the repository:

```bash
git clone https://github.com/mila-siamionava/mila-siamionava.github.io.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
